# Eve — Stellar Blade Hermes Pet

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://github.com/BunnyCode/hermes-pet/blob/main/LICENSE)

Custom animated 16-bit pixel-art Hermes coding pet.

## Included

- `pet.json` — Hermes pet manifest.
- `spritesheet.webp` — runtime sprite atlas used by Hermes.
- `spritesheet.xcf` — editable GIMP source sheet.

## Install

Copy this repository’s contents into:

```text
~/.hermes/pets/eve-stellar-blade/
```

Then select it in Hermes with `display.pet.slug: eve-stellar-blade`.
